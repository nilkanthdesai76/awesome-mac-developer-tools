# Contributing to Awesome macOS Developer Tools

Thank you for helping curate the best developer tools for macOS!

### Submission Guidelines

- **Quality First**: The tool should be actively maintained, stable, and widely useful for developers.
- **Format**:
  ```markdown
  | **[Tool Name](https://tool-website.com)** | Brief 1-sentence description. | License | `brew install --cask tool-name` |
  ```
- **Category**: Ensure you place the tool in the most relevant section.
- **Alphabetical Order**: Keep tools in alphabetical order where possible.

### How to Submit

1. Fork the repository.
2. Create a new branch: `git checkout -b add-my-tool`.
3. Commit your changes: `git commit -m "docs: add MyTool to API Debugging"`.
4. Push to your branch and open a Pull Request.
